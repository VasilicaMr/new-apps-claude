# 04 · iOS app (CodeRelay)

## Screens
1. **Onboarding** (first launch): 4 pages explaining the concept, privacy, Apple Intelligence, and Mac setup.
2. **Hosts**: paired Macs (online dot when seen via Bonjour), Macs found on the network, "+" → *Add by address…* / *Try the demo*, and a getting-started card.
3. **Pairing sheet**: six code boxes (one-time-code keyboard), plus host and port fields for manual entry.
4. **Workspace** (one Mac): connection banner with Retry, a "Claude not found" warning, **New Claude session** (project picker with search and a permission mode; *Bypass* asks for confirmation), and the session list (● running).
5. **Session (the terminal)**
   * `❯ prompt` lines in mint, `⏺` assistant text with inline Markdown and a streaming cursor `▍`.
   * Tool calls: `⏺ Bash(git status)` plus a `⎿` first output line. Tap to expand.
   * **Permission card**: Details, ✨ Explain (Apple Intelligence), Deny / Allow. Haptic alert on arrival.
   * Per-turn `✓ 4.2s · $0.0123` and the running total in the header.
   * Composer: multi-line field, ✨ refine (Apple Intelligence), Send, or Stop while Claude works. Follow-up suggestion chips appear above it.
   * Menu: Summarize (AI), Rename, Interrupt.
6. **Settings**: font size, haptics, Apple Intelligence status and toggles, forget Macs, disclaimer.

## Connection lifecycle
* `WorkspaceViewModel` owns the one live `HostConnection` per Mac and routes `event` / `history` messages to cached `SessionViewModel`s.
* When the app returns to the foreground (`scenePhase == .active`), it reconnects if needed and re-`attach`es every open session. History replay rebuilds the transcript exactly, including pending permission cards.
* iOS suspends sockets in the background. Claude **keeps working on the Mac**, and you catch up when you reopen the app.

## Design system
Terminal aesthetic in `Presentation/Theme/Theme.swift`. Background `#0B0D10`, accent phosphor mint `#5CF2B5`, tool blue `#79C0FF`, warning amber, AI violet `#D2A8FF`. All text uses SF Mono, and the app is forced to dark mode. The app icon is generated by `tools/make_icon.swift`.

## Required Info.plist keys (set in `project.yml`)
* `NSLocalNetworkUsageDescription` and `NSBonjourServices = [_coderelay._tcp]`. Without these, discovery silently finds nothing.
* `ITSAppUsesNonExemptEncryption = false`. The app only uses OS-provided TLS, which is exempt.
